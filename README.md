# 3dquote · 加工报价小工具

> 一个用于 3D 打印 / CNC 雕刻 / 激光雕刻等工艺的网页计价工具。  
> 前端是一个单页 HTML，后端是 Python API，可通过 Docker 一键启动。

---

## 功能概览

- 💰 **按体积/时间自动报价**：根据模型体积、预计打印/加工时间等参数计算价格  
- 🧵 **支持多种工艺**（可扩展）：
  - FDM 3D 打印
  - 光固化 3D 打印
  - CNC 雕刻（木材、石材等）
  - 激光雕刻 / 切割（亚克力等）
- 🏭 **多厂商 / 多设备管理**：
  - 可配置多个厂商
  - 每个厂商支持多种工艺和设备
- ⚙️ **灵活成本配置**：
  - 设备小时成本
  - 材料单价
  - 后处理工时及单价（打磨、上色等）
- 🌐 **纯前端页面**：适合嵌入到自己的网站或后台管理系统

> 具体字段、算法逻辑请查看 `3d_quote.html` 和 `quote_api.py` 源码中的注释。
